# 计步详情原版布局还原

## 对照来源

本机 PunchCard 的 `PCCardDetailsViewController`、`BCWalkStepDetailView`、`BCCircleProgress`、`BCWalkDetailLabel`、`BCChartView` 和 `BCCardResultView`。本次依据源码尺寸、颜色、字体及资源重建 SwiftUI 页面，不修改 PunchCard 工作区。

## 页面与交互

- 移除原来的顶部分段切换条，改为左右滑动的详情／卡片两页，右上角显示两枚 6pt 圆点。圆点可点选，也有无障碍标签。
- 详情：190pt 渐变头部、130pt 白色进度圆环、原版 DINCondensedC 数字、达标提示及每日目标；圆环下方恢复距离趣味描述。
- 三列指标：公里、大卡、活跃时间，110pt 高度；活跃时间使用小时／分钟格式。
- 图表：160pt 高度、原版细圆角柱、浅色横线及 0／6／12／18／23 点标记；未读到的时段不绘制零值。男女步行插画以 20% 不透明度固定在底部。
- 卡片：原版香蕉底纹、主题底色、浅色圆形、步行人物大图、步数标题、距离描述和鼓励语。
- 分享使用与当前页同一套布局，附 KeepUp 和记录日期，继续支持预览、保存和系统分享。
- 目标设置、最近七天和估算说明保留在辅助菜单中，避免挤占原版内容区域。

## 明确保留的差异

- 导航栏沿用 KeepUp 当前系统样式，额外保留辅助菜单。
- 距离趣味文案采用原版阈值和中英文文案，但稳定选择一项，避免原版随机选择造成刷新闪变。
- 已知零值显示 0，未知值显示破折号；不复现原版将零值与缺失值混用的行为。
- 权限拒绝、设备不支持和读取失败时保留可操作的状态提示；正常状态没有说明长列表。
- 分享底部使用 KeepUp 品牌，不使用原版的品牌／二维码。

真机传感器与后台行为不属于本次 UI 还原验收。
