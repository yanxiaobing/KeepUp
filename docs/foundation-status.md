# 工程基础进度

日期：2026-09-16。本文记录初始基础阶段，后续进展见[体重记录与目标](weight-cards.md)及 README 文档目录。

## 已实现

- 独立 `KeepUp.xcodeproj`，App、单元测试与 UI 测试三个 target；iPhone、iOS 26.0+，Bundle ID 为 `com.bestlife.keepup`。
- Swift 6、SwiftUI、Observation；复用 PunchCard 的日历、时间线、我的布局与 51 组原版图片资源，底栏中间按钮进入选卡。
- 6 张基础卡：健身、散步、吃水果、拒绝碳酸饮料、不吃宵夜、俯卧撑。覆盖完成型、分钟型与整数次数型输入；散步目前为手动记录。
- 选择今天或过去日期，从中间 + 或补打卡入口进入分类/搜索列表；使用原版布局的数字键盘或完成型弹层录入，保存后显示票卡、日期标记、时间线和详情；删除需要系统确认。
- 累计记录数、记录天数与当前连续天数；同一天多条记录只计一天，今天尚未打卡时允许从昨天延续连续天数。
- 英文和简体中文 String Catalog、跟随系统或应用内选语言、深色外观、动态字号。辅助功能大字号采用系统日期选择器。
- WCDB 2.1.16 本地存储；数据库 schema version 2（包含本地资料）、稳定 UUID、固定归属日期、时区、真实录入时间和单位快照。重试同一草稿不重复插入，新草稿可同日独立保存。
- actor 封装数据库，串行初始化 ORM 与表结构；拒绝直接打开高于当前版本的数据库，避免重置用户数据。
- 初次加载失败可重试；保存与刷新交错时补做刷新，避免界面停留在旧结果。
