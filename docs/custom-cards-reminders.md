# 自定义卡、固定卡、每周进度与提醒

2026-09-17，继续对照 PunchCard 源码及参考模拟器实现。适配 iOS 26：业务插画与布局沿用原版，导航、开关、时间选择和确认弹窗使用系统控件。

## 已接通的流程

### 自定义卡

- 创建入口 → 7 个原版形象的横向选择 → 名称 → 单位 → 确认。
- 支持无单位、分钟、米、个、次、秒；无单位使用完成型打卡，其余进入数字键盘。
- 当前名称沿用原版布局限制：最多 5 个汉字或 10 个字母/数字，不允许空格、标点或表情。
- 新卡出现在原版“最近”列表，与最近使用的普通卡去重合并；不新增分类。
- 列表更多菜单可移除自定义卡，保留历史打卡及图片/文字。移除时同时清除该卡的固定显示、进度和提醒设置。
- 再次以相同名称、形象和单位创建，可恢复原卡 ID。重复确认不会生成多个同款卡；不同单位分别保留。
- 自定义图像同步用于日历、记录详情和分享。

### 固定卡及每周进度

- 数字/完成型录入的闹钟按钮、日历记录长按菜单、记录详情菜单均可打开提醒设置。“我的 → 闹钟管理”可以统一修改。
- 固定卡在今天未打卡时显示待打卡，复用原版待打图、角标及提醒图标；完成后替换为真实记录，次日重新出现。
- 每周进度按周一至周日的不同打卡日期计数，同日多条记录只计一天。按原版放在卡片底部标题上方，仅显示当天卡片的本周进度。
- 关闭全部选项即移除设置，历史记录不受影响；离开未保存页面会提示放弃修改。

### 提醒

- 选择本地时间、周一至周日，首次启用时请求系统通知权限。拒绝授权时保留编辑内容并明确提示未保存。
- 使用 UserNotifications，保存/删除设置、打卡/删除记录、前台恢复及语言切换后更新本机待发送队列。
- 当天已经打过对应卡时不再安排当天提醒，后续日期继续保留；修改/移除目标时清理旧队列。
- 英文通知使用英文卡名；自定义名称原样保留。英文帮助插画的中文标牌和手机屏幕由本地化视图覆盖，原图片文件不修改。
- 点击提醒可进入对应卡片录入；通过独立路由保存通知目标，等本地数据就绪后再打开。

## 数据与实现

WCDB schema 4 新增 `card_targets` 和 `archived_cards`。自定义卡仍保存在 `cards`，名称和形象分别保存于现有 titleKey、symbol 字段，以独立 UUID 标识。归档标记不会删除历史关联数据；创建相同卡时撤销归档。

每周统计使用固定民用日期和公历周一起点。通知按公历日期及本地墙钟时间安排，避免系统采用其他历法时误用年份。队列更新串行合并，旧快照不会覆盖新设置。

## 验证

本轮使用 iPhone 17 Pro / iOS 26.5 模拟器，构建部署目标仍为 iOS 26.0。

- `CustomTargetsFinal.xcresult`：20 个业务测试函数通过；自定义卡中英文创建、无单位/数值打卡、移除保留历史、恢复原 ID、重启恢复、提醒设置和语言切换等 5 条 UI 流程通过。该包整体失败的原因是系统队列中的英文卡名问题，之后已修复并专项复测。
- `ReminderQueueVerified.xcresult`：实际向 UNUserNotificationCenter 写入请求、检查英文通知正文、打卡后移除相应日期请求、保留后续请求、删除自身队列通过；固定卡/每周进度/删除设置流程通过。
- `CustomTargetsUIThird.xcresult`：日历范围与补打卡、英文保存/重启/删除、大字体三条基础 UI 回归通过。该包早期的中文退出点击问题已在 `CustomTargetsFinal` 的对应流程复测通过。
- `ReminderRoutingMainThread.xcresult`：App 进入后台后，真实系统横幅出现并点击，成功打开对应 Exercise 数字录入页。测试发现并修复了通知完成回调在后台线程触发 UIKit 快照导致的闪退。
- `ReminderRoutingVerified.xcresult` 的英文提醒设置流程通过；该包早期通知点击失败已由上面的主线程修正测试替代。
- 合计 20 个业务测试、1 条系统通知队列集成测试、5 条新增 UI 流程及 4 条基础 UI 回归分批通过。298 条本地化和 304 个原版 imageset 的 709 个文件校验通过。
- 新增业务测试覆盖重复创建、非法名称/单位、归档后的数据保护、目标验证、同日去重、跨周及夏令时、本地通知数量上限。
- 截图保存在 `.build/ui-review/KeepUp-Custom-*`、`KeepUp-Reminder-*`、`KeepUp-Pinned-Card-Chinese.png` 和 `KeepUp-Weekly-Progress-Chinese.png`。
- `.build/ReferenceUIHarness` 增加自定义卡/单位/提醒的只读展示入口；原 PunchCard 工作区未修改。直接启动单位页的参考截图含调试入口带来的导航栏，仅用于比较单位区域布局。

## 尚需完成
