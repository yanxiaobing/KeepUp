# 功能对齐执行清单

更新：2026-09-20。依据当前 KeepUp 实现与本机 PunchCard 源码。状态以本文件对应批次为准，较早文档中“计步、跑步尚未实现”等描述属于历史记录。

用户已明确：优先完成功能对齐，真机验证不阻塞继续开发。后续按下列顺序实现、用可控传感器样例与存储/UI 回归验证；真实传感器和地图效果的观察单独记录，不把它们当作每一批工作的前置条件。

## 已实现基础

- 普通卡与自定义卡的录入、历史补卡、删除、常驻/目标、未来计划及提醒；体重与起床的专用流程。
- 计步权限、今日/历史读取、目标、达标自动打卡及删除后防重建；中英文检查和提醒失败重试。
- 户外跑步开始、暂停、继续、结束、丢弃，GPS 过滤与断段，有效时长、距离和完整公里分段；草稿检查点、进程恢复暂停、结束事务与重复提交保护。
- 跑步历史详情、旧手工记录回退；WGS-84 存储/算距与大陆地图展示适配。

这些是可用流程；已完成的运动设置、详细指标和分享见下述批次，不能据此宣称全 App 已完成对齐。

## 已完成：骑行与室内跑步核心流程（F11、F12）

以下核心流程已实现并通过存储与 UI 回归。原版更完整的运动设置、曲线和分享仍按后续批次继续，不能把本轮核心流程等同于全部运动功能完成。

| 项目 | 对齐规则 | 本轮完成条件 |
| --- | --- | --- |
| 三种模式 | 户外跑步、室内跑步、骑行写入稳定模式字段；旧户外 JSON 缺少字段时默认户外 | 旧草稿/历史仍可解码；恢复以记录模式为准，不能由页面选择器覆盖 |
| 骑行入口与存储 | `punchcard.96`，公里；原版结果类型 2 | 今日入口、计划完成、返回进行中、历史详情均用骑行；保存不得进入跑步卡 |
| 骑行距离与速度 | GPS 距离；结束门槛统一为 **至少 500 米**；平均及分公里显示 km/h | 499 米不可保存、500 米可保存；GPS 合理速度上限与跑步区分；零时长显示占位 |
| 室内模式 | 与户外同属 `punchcard.2`，公里；原版结果类型 1 | 跑步准备页可选择室内；不展示地图、不要求定位授权或 GPS ready |
| 室内传感器 | `CMPedometer.distance` 的累计米数及累计步数；运动与健身权限 | 区分未授权、拒绝、不支持距离与真实零读数；无系统距离时不伪造步长估算 |
| 室内暂停/恢复 | 只累计运行区间；结束门槛 **至少 100 米** | 新区间重新建立基线；暂停期间与进程退出期间步数/距离不补入；重复、倒序和迟到回调不重复计数 |
| 室内结果 | 有效时间、距离、配速、步数、平均步频、完整公里分段 | 保存、重启读取、删除、失败重试与户外采用相同事务规则；GPS segments 为空 |
| 共用会话约束 | 同一时间只有一项运动 | 切换到其他运动入口时回到已进行的会话；结束/丢弃后才能开始另一项 |

原版阈值读写存在 `<100/500` 与 `>100/500` 不一致，KeepUp 使用统一包含等号的门槛。原室内实现用低频定位维持后台，但不拿 GPS 算距离；KeepUp 不把这段旧实现误变成室内强制定位授权。自动暂停和语音已在下述 F13 批次接通。

## 已完成：运动设置 F13

已建立强类型 `Defaults[.runningSettings]` 及单一设置模型，设置页与运动中设置复用状态。下列功能已接入实际运行行为，具体实现和回归记录见 [运动设置](running-settings.md)。

1. **准备与显示设置**：运动前确认、默认室内/户外模式、3→2→1 倒计时、平面/卫星地图。默认值对照原版：确认开、语音开、自动暂停关、平面地图、每 1 公里播报；其余布尔项原初始化为关。取消倒计时不创建草稿、不启动运动记录；准备页 GPS 就绪检测不计入运动，重复点击只开始一次。室内隐藏地图选项。
2. **常亮与防误触**：常亮只在进行中的运动按设置生效，暂停/结束/离开对应状态后恢复系统行为；原版“自动锁屏”是 App 内操作区防误触，不是锁定设备。实现明显的解锁手势，锁定时不能误结束/丢弃，系统权限和错误提示仍可访问。
3. **自动暂停/恢复**：区分用户手动暂停与自动暂停，只有自动暂停允许传感器自动恢复。原室内依据约 15 秒没有新步数，户外依据移动样本/GPS 状态；分别定义状态机，复用现有时间与分段规则。验收“停走→自动暂停→恢复”“手动暂停时移动仍不恢复”“弱 GPS 不产生跨段直线距离”。
4. **语音播报**：总开关、0.5/1/2/5 公里频率、语音来源及试听，开始/暂停/恢复/结束提示。中文原素材和英文语音分别接通；每个距离门槛仅播报一次，批量数据跨多个门槛不得重复轰炸，暂停/恢复不重播已播里程。关闭开关立即停止排队语音。
5. **设置持久化与恢复**：重启保持选择；恢复旧会话时沿用明确记录的必要参数或当前策略，不能悄悄变更运动类型。补设置往返、倒计时取消、手动/自动暂停隔离、常亮清理、语音去重的回归。

源码依据：`PunchCard/Cards/RunCard/Run_Setting/Class/BCRunSettingViewController.m`、`BCRunConfigViewController.m`、`Services/BCRunConfigService.m`、`Running/MainUI/BCRunningViewController2.m`、`RunningInDoor/BCRunningInDoorViewController.m`。已复用两套原中文语音资源，素材缺项和配速/速度由中文系统语音补齐，英文使用英文系统语音。

## 已完成：运动汇总 F17（运动部分）

按全部/单模式、全部时间/月汇总次数、去重天数、距离、有效时间、热量和最长距离，单模式显示加权平均配速或速度；按日查看并打开运动详情，删除后同步刷新。schema 11 增加轻量时长摘要，保留历史热量、不加载全部历史轨迹。详见[运动统计汇总](running-statistics.md)。
