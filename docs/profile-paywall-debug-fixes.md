# 会员墙、广告调试与个人信息修复

## 本次调整

- 对照 PunchCard `IapCloudCell` 恢复 80pt Cloud 权益模块：中央云朵、iCloud 字样、同步箭头，以及“私有存储 / 隐私安全 / 自主可控 / 设备同步”四项渐变字号文字。此处是会员墙 UI 还原，CloudKit 同步实现状态不因本次修改而变化。
- 英文会员墙标题为关闭和恢复按钮预留空间，避免长标题重叠。
- 退出优惠文案恢复“放弃优惠继续”，英文为“Skip offer and continue”。
- 商品列表缺失或加载失败使用独立 `productLoadError` 状态，页面内显示错误和重试，不在打开会员墙或回到前台时自动弹确认框。购买、恢复购买的操作反馈仍使用原有反馈机制。不可用商品继续禁止购买，价格以 StoreKit 实际结果为准。
- 在 Google SDK 请求入口按实际格式替换 Debug 广告位，覆盖开屏、普通插屏、激励视频。limited 页激励后插屏调用的是普通 Interstitial，因此使用普通插屏测试 ID。Release 使用原配置广告位，广告开关、隐私同意和会员免广告策略保持原有判定。
- 个人信息编辑在打开菜单、尺子或返回前结束输入并提交昵称；保存按顺序完成，返回等待保存结束。保存失败留在当前页显示原因，昵称可以再次提交；头像选择返回不再重新覆盖昵称草稿。各类尺子显式独立标识，避免跨类型复用状态。

测试广告位来源：[Google iOS 测试广告文档](https://developers.google.com/admob/ios/test-ads)。目前工程没有 Banner、Native 或 RewardedInterstitial SDK 加载入口，因此没有新增这些广告格式。

## 回归范围

- 单元测试：商品缺失不弹窗、显式重试、Debug 各格式测试 ID，以及现有会员、广告、资料与本地存储测试。
- UI 回归：恢复后的会员墙退出文案；昵称不按键盘完成而直接返回；性别修改；出生年、身高、体重连续编辑、保存、重新打开，以及取消不保存。
- 英文和简体中文字符串、预置配置验证。

已通过 290 项单元测试（281 项 Swift Testing + 9 项 XCTest）和三条专项 UI 场景。UI 截图确认中英文会员墙、个人信息和尺子；商品不可用场景使用 Debug 启动参数固定复现，不连接实际 StoreKit 商品服务。Debug / Release 广告位解析分别执行断言通过。真实广告展示、购买交易不包含在本次模拟器验收中。

最终 Release 模拟器构建通过；英文标题避让、页内重试与退出、滚动查看完整 Cloud 模块的最终 UI 回归通过。

后续按反馈将个人信息页的头像、性别选择，以及首次填写资料的头像选择改为系统底部 Sheet，取消选项单独一行。

操作区再次对照原版收紧：商品轮播 99pt、按钮上间距 20pt、购买按钮 56pt、辅助按钮上间距 16pt、辅助文案布局 16pt，加底部安全距离。辅助按钮扩大触摸区域但不撑高布局。商品异常与重试复用轮播顶部 55pt 信息区，不再额外增加整行；滚动内容底部留白改为测量操作区实际高度。皮肤权益标题改为“解锁全部皮肤”，会员显示“已解锁全部皮肤”，不再复用皮肤列表名称。

头像菜单使用系统底部 `.sheet` 容器，内容为拍照、相册和独立取消按钮，复用于首次填写资料和个人信息页；性别菜单共用同一底部 Sheet，提供男、女、取消。选择头像来源后先关闭 Sheet，再打开相机／相册，支持下滑关闭。已验证性别保存、两处菜单取消、相册选图裁剪以及个人信息保存。
