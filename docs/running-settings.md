# 运动设置与语音

更新：2026-09-20。对应功能清单 F13，继续沿用 QuitSmoke 学习后的强类型 Defaults 封装与现有 WCDB 会话存储，不额外建立一套偏好读写。

## 原版依据与默认值

对照 PunchCard 的 `BCRunConfigService.m`、`BCRunSettingViewController.m`、`PCPunchCardService.m`、`BCRunningViewController2.m`、`BCRunningInDoorViewController.m` 和 `BCRunAVAudioPlayer`。

| 设置 | 默认值 | 实际行为 |
| --- | --- | --- |
| 运动前确认 | 开 | 显示准备页；关闭后在权限与数据源就绪时自动开始，每次进入最多自动尝试一次 |
| 默认跑步方式 | 户外 | 可选室内；骑行入口仍为骑行，已有会话始终保持其记录的类型 |
| 开始倒计时 | 关 | 3→2→1 后创建会话；取消、退出、进入后台均取消，不写入草稿 |
| 语音播报 | 开 | 开始、暂停、恢复、成功保存结束以及距离里程播报；关掉立即停止当前及排队音频 |
| 自动暂停 | 关 | 15 秒无有效移动后自动暂停，保持数据源用于检测恢复 |
| 自动锁屏 | 关 | 保护 App 内运动操作区，长按 1 秒或辅助功能操作解锁，开始/继续时重新锁定 |
| 屏幕常亮 | 关 | 仅运动页可见、处于前台且正在记录时保持常亮；暂停、设置弹层、离开、结束及后台恢复原系统值 |
| 地图 | 平面 | 可切换卫星，准备页、运动页、历史详情共用；室内隐藏地图设置 |
| 播报频率 | 1 公里 | 可选 0.5、1、2、5 公里 |
| 中文语音来源 | 第二套原语音包 | 两种原素材可选和试听；英文使用系统英文语音 |

“运动前确认”对应原版是否经过准备页，不额外弹出确认框。准备页可能提前检查 GPS 就绪，但倒计时完成前不计时、不累计距离、不保存会话。修改默认类型在关闭设置时同步到无会话的跑步准备页；只改其他设置不会覆盖当前手选模式。

## 暂停与恢复

- 手动暂停停止数据源，移动不能自动开跑。撤销权限、进程恢复、关闭自动暂停开关也进入手动暂停。
- 自动暂停期间的时间、位移和步数不计入结果；GPS 恢复建立新轨迹段，室内恢复重新建立累计读数基线。
- GPS 自动恢复要求暂停之后的有效移动点，过滤不合理位移；未知速度时须超过定位精度范围，避免小幅抖动开跑。
- 室内迟到的暂停前累计读数只更新基线，不触发恢复；恢复样本必须新于暂停时刻且足够新鲜。
- 恢复进程时只保留最后可靠检查点并暂停，不恢复自动开跑状态。设置使用当前持久化策略，记录中的运动类型不变。

## 语音与资源

复用 `audio.bundle` / `audio2.bundle` 共 79 个原 MP3；资源来源与 SHA-256 纳入 `punchcard-resource-manifest.json`。两套历史语音包并非完全对称：缺失的骑行片段以及配速/速度词汇由中文系统语音补齐。英文整句播报距离、有效时间和配速或速度；语音来源选择主要影响中文原素材。

距离用实际进度高水位去重：静音时仍推进，改变频率和恢复会话不补播旧里程。GPS 同一批样本只发一次最终进度，跨过多个门槛只播最新门槛。保存失败不宣告结束，成功持久化后才播报。试听离开即停，且不会误停已经替换试听的正式运动提示。

播放队列串行处理原录音和系统语音；新提示替换旧队列。音频会话仅在播放时激活，结束释放。工程声明 `audio` 与已有的 `location` 后台能力，不通过循环静音维持运行。

## 设置存储

使用 `Defaults[.runningSettings]`，SwiftUI 用 `@Default` 订阅；`AppModel.refreshRunningSettings()` 统一通知运动引擎和语音服务。语言切换也刷新语音。解码缺少的设置字段保留默认值，给未来新增选项留出兼容性；测试重置入口覆盖这一设置。运动草稿继续由原 WCDB 检查点与结束事务保存，本批不增加数据库版本。
