# 体重记录与目标

日期：2026-09-17。最低 iOS 26.0；本机使用 Xcode 27、iPhone 17 Pro / iOS 26.5 模拟器验证。

## 已实现

- 复用原版体重输入弹层、橙色箭头、横向尺子、BMI 文案和提醒入口。范围 5–200kg，精度 0.1kg；初值取最近记录或个人资料。
- 同一日期再次记录更新原记录，保留记录 ID、备注、已发布照片/文字及草稿。重复提交同一操作不会覆盖后续的新值。
- 资料页修改体重同步创建或更新当天记录；当天体重待办完成后继承备注，并在同一 WCDB 事务中移除待办。
- 原版体重日历票卡、插画详情、BMI、分享预览；详情沿用原项目当前启用的 `BCCardResultView`，不启用原代码中已注释的旧目标详情分栏。
- “我的 → 体重目标”支持初始体重、目标体重、结束日期、每周变化提示、目标摘要和重置确认。目标范围 20–200kg，默认三个月，截止日期为明天至一年后。
- 设置目标同时保存当天起始记录；减重或增重达到目标后结束当前目标；重置保存新周期，取消编辑保留旧周期。历史记录保留当时的目标信息。
- 中文和英文文案；导航和日期选择保留适合 iOS 26 的系统控件。

## 数据与原版差异

WCDB schema 6 新增 `weight_target`、`weight_records`、`weight_operations`。操作回执与每日记录 ID 分开保存，避免重试旧请求覆盖最新记录。升级保留既有资料、普通记录、内容、待办、提醒目标和起床记录；跨卡片 ID 冲突被拒绝。

补录过去体重不会覆盖个人资料里的最新体重。新体重记录保存当时身高，之后更改资料身高不会改变历史 BMI；没有身高时提示补充资料。以上是相对原版的数据一致性处理，页面继续按原版还原。

资源累计 318 个原版 imageset、738 个文件，源文件、目标文件与清单的 SHA-256 一致。本轮加入目标猴子、日期图标、箭头及体重待办插画；本轮仅修改 KeepUp，原版截图使用 KeepUp 构建目录中的独立参考副本。
