# 普通海报鼓励语与个人页相遇天数

更新：2026-09-20，对应 F15/F19/F24 的本地功能差异。沿用现有 WCDB 记录与目标快照，schema 保持 11；不新增偏好或存储层。

## 原版依据与实现

原版 `Base/Services/PCValueMatchDesService.m:89–200` 的 `encourageDescriptionWithCard:` 由 `Cards/CardDetails/Views/BCCardResultView.m:111` 实际调用。除打卡次数外，还包含累计数量、全局连续打卡及体重达标分支。KeepUp 之前仅按次数提供一句鼓励语，本次补齐数据分支并集中到 `EntryEncouragement`。

- **次数与数量**：按相同卡片汇总记录次数；有单位卡按同卡、同单位的有效正数累计，保留一位小数。无单位和体重不求数量总和，未知、非法或不同单位的测量不相加。
- **连续打卡**：复用 `RecordStatistics.streak`，全部卡片按民用日期去重；今天未打卡时从昨天计算，中断则停止。详情打开时固定参考日期，预览与导出不会因跨午夜临时换句。
- **体重达标**：优先显示记录当时 `WeightRecord.target` 的减重/增重目标成果，显示实际体重变化与经过的民用天数，同日最少 1 天。不借用当前目标或当前体重；目标已清除或之后重新设置，也不改变历史记录的达标依据。
- **稳定展示**：原版从候选文案中随机选取；本次按记录 ID 稳定选择数据分支，同一份数据的重绘、导出和重启保持一致。数据变化后允许更新候选与结果。文案以当前真实累计记录为依据，不声称是该历史日期截至当时的统计。
- **双语及排版**：全部文案进入字符串目录，英文区分 1 day；海报底部文字使用自然高度，取消固定 50pt 导致的多行截断。普通海报的预览和导出共用视图。

独立产品分发链接尚未配置，因此不复制旧产品二维码。原版多套随机修辞没有逐句搬入，但上述全部数据分支均可生成。

入口检查还补齐了日历中已保存计步卡的固定日期参数，与时间线历史入口一致，跨午夜不跳到次日；新建实时计步仍跟随今天，沿用已有控制器回归。

## 我的相遇天数及入口核查

个人页使用已持久化的 `UserProfile.createdAt` 显示第 N 天，按设备当前时区的日历日差加一，每分钟刷新；夏令时不按 86400 秒折算，未来或无效日期最少为第 1 天。昵称与天数限制可用宽度，支持中英文单行缩放。

已核查普通记录/步行统计的原版可达路径：没有把未调用、数值硬编码的统计 helper 新建成产品页面。明确保留下一批计步小时图表、活跃时间，以及独立客服/评分配置和主题兑换提示差异，见[入口核查记录](ordinary-statistics-entry-audit.md)。本次不等同于全 App 功能全部对齐。
