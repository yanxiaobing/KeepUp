# 户外跑步实现与验收

## 当前范围

接通今日跑步目录、首页待打卡/计划、长按打卡、未完成会话返回入口和历史详情。过去日期不能启动实时跑步，未来日期仍创建计划。只提供户外跑步，室内跑步和骑行尚未实现。

页面复用 PunchCard 的开始、暂停、继续、停止、GPS 和阴影资源，新增资源逐文件登记在 `punchcard-resource-manifest.json`。支持英文、简体中文。仍需逐页真机核对原版视觉和交互。

## 业务与存储约定

- `RunningLocationSource` 封装 Core Location，页面进入后预定位，用户明确授权且收到有效定位后才能开始。运行时启用已声明的 location 后台模式，结束/暂停关闭持续定位；关闭运动页面不结束正在进行的跑步。
- `RunningSession` 存储原始 WGS-84 坐标，计算有效时长、距离及每整公里用时。暂停不计时，继续后新建轨迹段；超过 30 秒的采样断档不跨段连接或累计距离。过滤无效坐标、精度超过 50 米、过期/未来、乱序、明显跳点及低速漂移。
- 固定开始时的自然日、时区和稳定记录 ID，不因跨午夜或系统时区变化改写归属。有效时长不包含进程退出后的间隔。
- 活动会话每 5 秒及生命周期/状态转换时保存检查点；恢复后停在上次检查点并置为暂停，由用户继续。没有根视图每秒重复写库。
- schema 8 新增 `running_sessions`，通过 `StoreTables` 与 `StoredJSON` 访问，同一个 `LocalStore` actor 处理。列表只读活动草稿，历史轨迹在详情按需读取。
- 递增 revision 防旧检查点覆盖；控制器串行提交检查点和终态操作。完成时必须达到 100 米，在单个 WCDB 事务中保存轨迹、创建唯一打卡并清理对应计划，计划备注会保留。
- 保存失败保留内存会话并显示重试，事务成功后才清除会话。丢弃与删除保留无坐标的终态标记，阻止迟到写入复活轨迹。结构校验拒绝不合法时间、坐标、分段和公里数据。
- 兼容旧手工跑步记录：没有独立轨迹时回退普通卡片详情。
- 地图展示沿用原版大陆坐标适配，存储和距离计算始终保留 WGS-84，详见 [坐标来源与验收限制](running-map-coordinates.md)。

## 自动验证

统一验证环境：Xcode 27.0、Swift 6、iPhone 17 Pro / iOS 26.5 模拟器。2026-09-20 已通过 68 项 Swift Testing、9 项提醒 XCTest 和 3 项跑步 UI 测试。501 条中英文文案、预置配置、770 份资源哈希、plist 和 diff 空白校验通过。

- 状态机、定位过滤、暂停断段、公里配速、权限撤销、进程恢复、写入失败及竞态测试。
- WCDB 重开、revision 顺序、完成幂等、计划原子清理、删除/丢弃防复活、单活动会话测试。
- AppModel 恢复仅执行一次、结束失败后重试测试。
- 地图外部数值样本、邻近地区与完整多边形差分测试。
- UI 使用明确 DEBUG 启动参数 `-ui-testing -ui-testing-running route` 注入轨迹；生产构建不含该来源。覆盖拒权、开始/暂停/继续/结束、唯一历史记录、关闭页面及重启恢复。该结果不代表传感器或后台定位真机验收。

## 真机待验收

1. 首次授权、仅一次授权、拒绝后设置恢复、关闭系统定位、撤销权限后暂停。
2. 室外开始，锁屏/切后台持续定位，返回查看时间和轨迹；暂停步行后继续，验证不连接暂停期间路径。
3. 低信号、断网和长时跑步的轨迹连续性、电量、内存及写入开销。当前位置精度不等于距离绝对精度，不应把模拟轨迹误差作为运动测量质量证明。
4. 强制退出后恢复暂停，短于 100 米的提示与丢弃，完成后重启及删除。
5. 大陆真实地图底图对齐，以及海外、港澳台和边界地区不误转换。
6. App Group 注册、真机签名，以及运动与健身计步权限/真实数据仍需原有验收。
